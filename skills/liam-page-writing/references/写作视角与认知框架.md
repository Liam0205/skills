# 写作视角与认知框架（L3-L5）

## L3 选题逻辑

### 什么时候写

| 触发 | 说明 | 例子 |
| - | - | - |
| 自己被坑过并解决了 | 主力来源。踩坑→排查→根因→记下来备查 | VSCode Remote-SSH 死循环、cmake -j 打爆内存、iOS 电池用量异常 |
| 别人问了同一个问题 | 「今天有人问到……这里一并回答」 | MacTeX 中文支持、hyperref bug |
| 中文世界缺一篇讲清楚的东西 | 明确的补白动机 | 「中文互联网圈子内似乎还没有对它们做完整解释的帖子，故有此篇。」 |
| 读到一篇/一本书觉得有意思 | 书评、读后感、赏析 | 《谈人生》《病梅馆记》、知乎魔幻现实主义文 |
| 学完一门知识想固定下来 | 「读懂 + 复述」驱动 | Dalio 经济学系列、英语语法十二篇、乐理漫谈 |
| 系列化的自我承诺 | 「这是一个新的系列」 | 博弈论通俗演义、英语语法、Dalio 经济学、越狱插件教程 |

### 切入角度

写的是**「我（我们）如何走到这个结论」的过程**，不是结论本身。三种常见切法：

1. **需求 → 朴素解 → 精巧解**（技术文）：先把能跑的办法摆出来，说明它为什么不够，再上正解。
2. **定义 → 推导 → 分支 → 结论**（科普文）：像写证明一样铺开，中途设一个「看似公平」式的反转。
3. **原文 → 串讲 → 我学到了什么**（书评文）：先复述，再提炼，落到自己的判断。

### 不写什么

- 不写新闻评论、不追时效性热点（2026 年前 403 篇几乎没有「评论今日事件」）
- 不写产品测评、不带货、无广告位
- 不写「X 个必知技巧」类清单文
- 不写纯情绪宣泄（情绪只在既有论证基础上作为调料出现：`这多脑残啊！`）

## L4 素材策略

### 素材类型与权重

| 类型 | 用法 | 出现频率 |
| - | - | - |
| **一手实测** | 自己跑出来的数据、日志、编译输出、性能剖析 | 技术文标配。占比最高 |
| **源码/官方文档** | 翻 pgfpages.sty、读 Claude Code 源码、查 texdoc | 高。「通过翻阅 pgfpages.sty 的源码，我们不难发现……」 |
| **原文引用** | 书、古文、歌词、知乎文章，标明出处并给链接 | 书评类必要 |
| **引言（名人/论文）** | Dijkstra 关于 quick and dirty 的话 | 点缀，全文量少但辨识度高 |
| **成语/古诗文** | 和光同尘、同流合污、病梅馆记、缄口不言 | 中文语感的锚 |
| **截图** | 报错界面、编译效果、原题题面 | 0.9 张/篇，见 L6 |
| **链接** | 站内旧文互链 + 站外参考 | 站内互链很密（「前作」「四年多以前我实现了水印功能」） |

### 权威对象的选择标准

- 只认**能自己验证的东西**：源码、实测日志、官方文档。不引二手转述。
- 引人也只引「说了实话的人」，不引头衔。引 Dijkstra 是因为那句话本身讽刺，不是因为他是图灵奖得主。
- 数据必须带出处和口径：「DX 的 GBRank 当标注 query 上升到 7--8w 量级时，有明显提升，对比目前我们的标注量是不到 4w。」

### 处理争议的方式

不回避，直接下判断，但把判断的依据先摆出来。CJK vs xeCJK 之争：「啥也不懂，瞎搞胡搞」——骂完之后用整篇文章讲清 CJK 为什么不通用。

## L5 认知框架

### 核心命题（五条，都不是显性说教，而是反复出现的行为模式）

**1. 讲不清楚 = 没想清楚。**

> 如果不能把自己所思所想用「他人」能够理解的方式，有逻辑地讲解出来，那么所谓的「有逻辑」都是幻觉。

这条决定了他的写作姿态：**写作是检验理解的工具，不是表达已有想法的容器**。所以文章里常有「我原以为……后来发现……」的自我纠错，也所以技术文必须逐步推演、不能跳步。写作动机自述为「一是为了防蠢，二是为了装屄」，防蠢排在第一。

**2. 工具服务于目的，研究工具本身是浪费生命。**

> 我有更好的选择，能够又好又快地达成我的目标，**我干嘛要浪费时间和生命在折腾这些工具上**？要知道，**我的目的是用工具来创造价值，而不是去研究工具本身**。

「用适合的工具做合适的事」——Vim、Emacs、LaTeX 各有所长，也都有不擅长的领域。反对把某个工具/方案当成信仰（CJK 拥趸、编辑器之争）。

**3. 从定义和分类出发推演，不从结论和权威出发。**

无论是经济（交易→支出/收入→信贷→周期）、博弈论（规则→收益矩阵→均衡）、还是 SVD（先定义矩阵分解），统一套路：

> 交易涉及到的标的物分成三类：1. 商品，2. 服务，3. 金融资产。

**先切开，再逐个推**。这是最稳定的思维指纹。副产品是「两个」一词的高频（182 篇）——二分/三分癖。

**4. 不作伪才有感染力。**

> 真诚而不作伪是打动读者的「大杀器」，写文十年深以为然。

允许自嘲（「理工男」「技术弱鸡」「防蠢」「装屄」），允许承认不懂（「考虑自己资质愚笨」），允许承认失败（「中间失败了一次」）。反面是「面子」和「人设」——那会带来偏见和作伪。

**5. 对流行正确保持怀疑，倾向自己验证再下结论。**

甩脂机有没有用、竖式开平方能不能手工做、三门问题怎么模拟、闪光同步到底是什么关系——都是「我先算一遍/跑一遍，然后告诉你」。对「众所周知」的用法有两种：一种是真的用它推演（线程创建有开销），一种是反讽。

### 价值观与审美

- **厌恶装腔**：鄙视「不懂装懂」「抱残守缺」「圈子潜规则」。
- **半文半白的审美**：认为古文简劲有味道（「名缰利索」「文人气」「古典气质」），白话容易啰嗦。所以正文里常掺文言连词与四字短语，但**粗话也用得干脆**（瞎搞胡搞、这多脑残啊、装屄）。两种声腔并存，不冲突。
- **对「讲不清前因后果的提问」有真实的不耐烦**：`我发现向我提问的人并没有这种将事情前因后果讲述清楚的能力；更多的时候，是类似「头疼砍头给医生、脚疼剁脚给大夫」的求问方式。`

### 判断「好」的标准

- 好文章 = 把前因后果讲清楚，读者能复现你的思考路径
- 好方案 = 能跑、代价清楚、不是为了炫技
- 好对象 = 有真问题、有实测数据、有不装的表达
