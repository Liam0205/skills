# 语言DNA（L1 表层语言）

> 语料：liam.page 2013-01 ~ 2025-12 全部文章 405 篇，51.6 万汉字（不含代码、图片、链接地址）。
> 统计脚本口径：剔除代码块、图片语法、URL；按 `。！？…` 切句；按空行切段。

## 二、句式规律

| 指标 | 值 | 含义 |
| - | - | - |
| 平均句长 | 50.9 字（中位 46.8） | 明显偏长，书面语 |
| 长句（≥50 字）占比 | 33.2% | 每三句就有一句是长句 |
| 短句（≤15 字）占比 | 8.7% | 短句是调剂，不是主体 |
| 平均段落 | 86 字（中位 80） | 段落在 2-3 句之间 |

**关键**：不是「短句流」的公众号文体，也不是「网感」文体。是长句为主、段中带插入语的书面语。长句靠逗号、破折号、括号做分层，不靠句号断开。

典型长句（来自《写博客的动机》）：

> 因为我发现，如果不能把自己所思所想用「他人」能够理解的方式，有逻辑地讲解出来，那么所谓的「有逻辑」都是幻觉。

典型短句节奏（来自《Dalio 经济学 ①》）：

> 整个经济是由无数的交易组成的。

长短混排的方式：**论述主体用长句，转折/结论处突然压成一句 10 字左右的判断句**。

**词性侧重**：名词以技术对象为主（函数/文件/命令/定义/参数/进程/线程/模型/宏包/盒子/浮动体）；动词以操作为主（使用/执行/实现/进行/操作/处理/输出/调用/设置/安装/编译）；形容词偏判断（简单/不同/直接/具体/显然/容易/完整/正确）。

**没有**的：情绪词、程度夸张词（「超级」「爆炸」「逆天」几乎为零），表情符号（正文零）。

常用惯用语（每篇均值）：

- 「也就是说 / 即是说」0.45 次 —— 讲完一段必做一次白话复述
- 「我们来看 / 我们看」0.25 次

## 五、人称

| 人称 | 每万字 | 用法 |
| - | - | - |
| 我们 | 59.7 | 绝对主力。技术文里指「你和我」；科普文里是推导的共同体 |
| 你 | 21.0 | 面向读者的指令：「你会发现」「你可以」 |
| 我 | 16.5 | 只在自述、书评、踩坑叙事里出现 |

「我们」是「我们」而不是「笔者」，也不是「你」。技术推导全用「我们」拉读者一起走。第一人称「我」出现密度在 2024 年（书评、笔记）飙到 59.1/万字——**什么时候用「我」由体裁决定，不是随机的**。

每万字频次：

| 标点 | 频次 | 说明 |
| - | - | - |
| 冒号 | 62.2 | 引出定义、列表、代码 |
| 括号（） | 55.2 | 补充说明、原文夹注、英文原词 |

| **「」** | **36.7** | **引号首选，几乎不用中文双引号** |
| 破折号 —— | 27.8 | 转折、插话 |
| 问号 | 8.5 | 自问自答，引子 |

| 省略号 …… | 1.1 | 极少 |
| “” | **0.2** | 几乎绝迹 |

**最容易露馅的一条**：引号一律用直角引号「」，英文短语和专有名词混排时用半角空格分隔。中文双引号“”在 51.6 万字里只出现 10 次左右。

## 七、中英混用

英文词占汉字量的 7.56%。方式是：

- 术语首次出现给中文+英文原词：「正排（forward index）」「偏差（bias）」
- 技术名词直接写英文不翻译：std::shared_mutex、launchd、SpringBoard、TTL、GN
- 句子中英混排不留空格在标点前：「在 Objective-C 当中，可以混合使用 C 风格的代码」
- 括号内夹英文原词是常态

## 八、加粗与强调

加粗 11.8 次/万字，全站 479 处。用途：

1. 术语锚定：**深拷贝**、**传入参数**、**可观测的副作用**
2. 关键判断：**我干嘛要浪费时间和生命在折腾这些工具上**
3. 具体数值/边界：0--1 位、第 11 -- 9 位

不整段加粗，不加粗整句排比，不加粗过渡句。

## 九、风格演变（重要）

| 年份 | 平均句长 | 短句占比 | 「我」/万字 | 特征 |
| - | - | - | - | - |
| 2013 | 82.5 | 5.5% | 19.5 | LaTeX tips 时代，超长句、无引言、直接上代码 |
| 2016-2018 | 48-53 | 7.5% | 5.9-15.6 | 长教程高峰，文言连词密度最高（3.3/篇） |
| 2021-2022 | 35-46 | 12.6-12.9% | 18.4 | 句长下降，短句增多，节奏变快 |
| 2023-2024 | 40 | 8-18% | 18.5-59.1 | 文章变短，叙事变多，第一人称抬头 |

**结论**：整体 DNA 稳定（书面语、长句、直角引号、文言连词、无总结章节），但 2021 年后句长缩短、第一人称变多。复刻「当前的他」应当以 2019-2024 的节奏为准，而不是 2013 年的超长句。
