# 视觉风格指南（L6）

> 站点是 Hexo + NexT 系主题，白底、无侧栏干扰、正文单栏。以下规律基于 405 篇的 Markdown 结构与 378 张图片的抽样查看。

## 一、总体基调

**朴素到近乎无设计**。没有封面图，没有题图，没有作者卡片，没有分割线插件，没有引用色块。文章就是字号统一的黑字白底加代码块。视觉信息全部由代码块、图片、小标题三者承担。

## 二、配图策略

| 指标 | 值 |
| - | - |
| 平均配图 | 0.9 张/篇 |
| 有图的文章 | 132 / 405（33%） |
| 图片总数 | 378（png 261、jpg 100、gif 7、其余杂） |
| 图片在文中的位置 | 前 1/3：29%，中 1/3：33%，后 1/3：39% |
| 表格 | 0.1 个/篇（几乎不用表格，宁可写成 bullet） |

三分之二的文章**完全没有图**。有图的文章集中在两类：LaTeX 教程（必须展示排版效果）和排错/实机操作（必须展示界面或报错）。

### 图片的五种功能

| 类型 | 内容 | 典型 |
| - | - | - |
| **渲染效果型** | LaTeX / PS / 终端输出的最终样子 | `tcb-basic.png`（tcolorbox 编译后的一排盒子）、`demo-reduced-print.png` |
| **问题证据型** | 报错界面、异常现象、原始题面 | `framed-question-need.jpg`（2015 高考理科 21 题截图，用来当作「需要有框的题目」这个需求的原型） |
| **界面操作型** | macOS/iOS 设置界面、软件 GUI 步骤 | 越狱、VSCode、SecureCRT 配色 |
| **数据/图表型** | 自绘示意图、曲线、架构图 | SVD、卷积、百度排名架构图 |
| **纯装饰型** | 极少 | 仅少数生活类文章 |

### 图文协作模式（最需要复刻的一条）

**引导语极短（2-8 字）+ 冒号 → 图 → 图后立刻解释**：

```
以下是效果：
![](...)

如图所示：
![](...)

截图：
![](...)

我们得到：
![](...)
```

图片前面的说明几乎不超过十个字，绝不用「如下图所示，我们可以看到……」这种长引导。图的解释放在图**后面**，或者根本不解释（效果图自己说明自己）。

图片文件名带语义：`framed-question-need.jpg`、`tcb-env-complex.png`、`markdown_inlineFootnotes_links.jpg`——先想清楚这张图要证明什么，再起名。

## 三、排版格式

| 项 | 规律 |
| - | - |
| 小标题 | H2 平均 2.7 个，H2+H3 共 5.2 个；107 篇无小标题 |
| 小标题字数 | 平均 8.1 字，多为名词短语 |
| 段落 | 平均 86 字（2-3 句），不用一句一段的短段落节奏 |
| 分隔方式 | 只用 H2/H3 和空行；**不用分割线 `---`、不用加粗句当隐性标题** |
| 加粗 | 11.8 次/万字，全站 479 处，只加粗术语、关键判断、具体数值 |
| 列表 | 平均 9 项/篇，用于并列条件、参数说明、步骤 |
| 表格 | 0.1/篇，几乎废弃（早期 LaTeX 文用过，后来改用 bullet） |
| 引用块 | 用于引用原文、古文、名人语，格式是「引用 + 出处行」 |
| 脚注 | 有 `[^1]` 语法使用，但不多 |

## 四、代码块

总数 3147 个，语言标记分布：

| 语言 | 数量 |
| - | - |
| 未标记 | 1581（早期文章普遍不标语言） |
| tex | 534 |
| bash | 295 |
| cpp | 244 |
| python | 183 |
| plaintext | 123 |
| c | 98 |
| html / sql / js / objectivec | 13-11 不等 |

代码块的呈现习惯：

- 代码里写中文注释（`# 读取宿主图像`、`// 1. 图像预处理`）
- 长代码用编号注释分段：`// 1.`、`// 2.a`、`// 2.b`，正文再按编号逐条讲
- 代码前常有一句「如下」「代码如下」「以朴素的办法……」
- 代码后必有解释，且解释会指名某个参数/函数：「这里，`\pgfpagesuselayout` 命令是实现缩印效果的核心命令。参数 2 on 1 的含义不言自明。」

## 五、色彩与强调

- 无彩色文字，无高亮底色，无灰底引用框设计（主题默认样式而已）
- 强调手段只有三种：**加粗**、**直角引号「」**、**破折号 ——**
- 引号一律「」，中文双引号“”在 51.6 万字里只出现约 10 次
- 从不用 emoji（全站正文零 emoji；唯一例外是 `愉♂悦` 这类字符游戏，属于 2010 年代网络亚文化残留）

## 六、复刻检查清单

- [ ] 标题与正文之间无任何图片、作者信息、摘要
- [ ] 全文图片 ≤1 张（除非教程必须展示效果）
- [ ] 图前引导语 ≤8 字 + 冒号
- [ ] 无分割线，无「隐性标题」加粗句
- [ ] 加粗只落在术语/判断/数值上
- [ ] 引号用「」
- [ ] 代码块带语言标记，代码内注释用中文
- [ ] 段落在 2-3 句、80 字上下
