最近写博客的时候，需要用到表格。然后不可避免地再次发现 Markdown 孱弱的表格语法，于是又一次不能忍。

于是发现了这个[神奇的网站](https://www.tablesgenerator.com/html_tables)。它允许你从 Excel 当中贴入设计好的表格，然后自动生成相应的 HTML 表格代码（及所需的 CSS 样式表）。

简直是神器！
